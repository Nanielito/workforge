## Add a repository health dashboard

Source: product_planning
Priority: high
Labels: feature, docs

## Automate stale issue review

Source: product_planning
Priority: medium
Labels: feature

Help maintainers review inactive issues without closing them automatically.

- Identify inactive issues
- Add them to the review queue
- Notify the assigned maintainer
